<img src="./hd-about.svg" width="620" alt="about"/>

> Computer science student at the University of Wollongong in Dubai,<br>
> majoring in artificial intelligence and big data.

I build machine-learning models and the web apps that put them in front of<br>
people. The part I care about most is getting a model to explain itself:<br>
CardioLens predicts heart-disease risk and shows which factors pushed it up<br>
or down, so the number arrives with its reasons.

<img src="./hd-projects.svg" width="620" alt="projects"/>

**[cardiolens-ai](https://github.com/arwin-tech/cardiolens-ai)** &nbsp; <samp>python, xgboost, shap, fastapi, react</samp> &nbsp; [demo](https://cardiolens-ai.vercel.app)<br>
Predicts cardiovascular risk from 11 health details and charts which factors<br>
raised or lowered it. 0.798 ROC-AUC on 14,000 held-out patients.

**[aether-ledger](https://github.com/arwin-tech/aether-ledger)** &nbsp; <samp>typescript, react, leaflet</samp> &nbsp; [demo](https://aether-ledger.vercel.app)<br>
A carbon-footprint calculator and a simulated 72-hour pollution map for the<br>
UAE, with air-purifier spots near schools and hospitals. BITS Tech Fest 2025.

**[unstuck](https://github.com/arwin-tech/unstuck)** &nbsp; <samp>typescript, next.js, gsap</samp> &nbsp; [demo](https://unstuck2026.vercel.app)<br>
For the hours between getting stuck on coursework and asking someone: it<br>
turns the stall into one specific question. Built for DesignAthon 2026.

**[uowd_odyssey](https://github.com/arwin-tech/uowd_odyssey)** &nbsp; <samp>typescript, react, framer-motion</samp><br>
Front end for the UOWD Hackathon 2026 site, with teams, submissions,<br>
judging and admin all working in the browser.

Every graphic here is drawn by this repository, not loaded from anyone<br>
else's server. The portrait is a photo pushed through a 13-character ramp by<br>
<samp>[make_portrait.py](scripts/make_portrait.py)</samp>; the numbers are redrawn each morning by
[a scheduled action](.github/workflows/refresh-stats.yml)<br>
straight from the GitHub API, which commits only when something changed.<br>
